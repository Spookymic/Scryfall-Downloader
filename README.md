Simple HTML file to mass download high quality (300 DPI) Scryfall Scans.

## Usage

1. Export your deck from [Moxfield](https://www.moxfield.com/).
2. Open the HTML file in your browser.
3. Paste your decklist.
4. Select a language (default: English).
5. *(Optional)* Check "Fallback to English if unavailable" to automatically download the English version when a card is not available in the selected language.
6. Click **Download Images** and allow your browser to download multiple files.

Files will be stored in your downloads folder.

## Versions

- `decklist-downloader.html` — Full version with download counter and summary.
- `decklist-downloader-nocounter.html` — Lighter version without card counter.

## Sample format

```
1 Magda, Brazen Outlaw (KHM) 312
1 Mana Vault (5ED) 388
1 Mayhem Devil (WAR) 204
1 Mountain (SLD) 242
```
